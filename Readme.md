# Expense Tracker

A simple expense tracker built with HTML, CSS and JavaScript.

It helps you keep track of your income and expenses in one place. You can add transactions by category, see your current balance and check how much you have spent today.

## Features

- Add income and expenses
- Choose from different categories
- See your current balance
- Track today's expenses
- Delete transactions
- Save your data with `localStorage`

## Built With

- HTML
- CSS
- JavaScript

## How to Use

Open the project in your browser and start adding your income and expenses. Your data will stay saved in your browser using `localStorage`.

A simple and convenient way to manage income, expenses, and daily spending, with data stored locally in the browser.
